# V4 增量实验记录

本轮在既有 SceneGenerator 上完成五方向的第一轮实现和实验。原始 baseline 目录保持独立；不改为位姿图，不引入细节人体。双车 Step20/50 与人物 Step20/50 均只用本阶段 RGB、剧本与同次 VGGT 结果，相机固定。

## 拟合器的证据

- V4 全部新项关闭，与 V2 的受控位姿结果最大差异为 0。
- 已比较软包含、局部参考系、分阶段/交替优化、可见深度、空闲空间与组合。
- 已知形状的干净场景：可见深度使平均位置误差约 0.269 → 0.032，体积 IoU 约 0.373 → 0.945。
- 真实遮挡受控场景：位置误差约 0.265 → 0.043，mask IoU 约 0.723 → 0.928。
- 错误点对应受控场景：位置误差约 0.291 → 0.032，mask IoU 约 0.678 → 0.944。
- 软包含/空闲空间在这几组中额外收益很小；有意缩小的错误代理形状仍不能仅靠位姿修正。点全在体内不代表体积正确。
- 硬固定初始局部点中心、朴素交替策略存在负面结果；未选择全开。
- 双车等预算测试存在指标取舍，不能从低重投影误差或低盒外点比例宣称三维正确。没有把候选设为默认。
- 另外尝试现有 V3 的共享形状修订，增加 160 步，作为独立 Agent 修订实验，不混入等预算消融。

## 共享表示与人物

- 场景状态支持刚体组合和五截面粗柱体，弯曲局部控制去掉常量/线性分量，避免与根位姿重复。
- 拟合与渲染读取相同粗笼子状态，非零径向控制的 NumPy/Torch 顶点一致性也有测试。
- 当前拟合器只估计弯曲和共享尺寸；非零径向输入会明确拒绝，渲染本身支持它。
- 已知形变场景中，刚性/形变平均世界顶点误差约 0.0905 / 0.0250。两帧无 mask 仍保留实体并标注推断。
- 生成单人视频中比较刚性粗柱体与可弯曲粗柱体；没有头部、分离四肢或解剖细节，不能解释为完整人体恢复。
- 视觉检查暴露墙面 plane 被通用初始化误当水平面。Agent 复用 vertical_surface 修订；初始化增加 wall/vertical_surface 角色分支，并用已知墙测试验证方向。

## 实体优先级与 Agent

- 剧情角色与几何职责独立：关键人物/道具高优先，次要遮挡/支撑物仍保留，非必要装饰可仅描述。
- 策略生成固定总预算的实体执行计划；现有稀疏/形变拟合器实际读取预算，人物实验使用了该通道。
- 表示/运动类型不匹配被列为需要修订，不能默默替换几何；重要实体和有几何职责的实体禁止 description_only。
- 当前对话 Codex 负责看 RGB、身份和边界、定义场景关系、查看诊断并修订。没有外部 VLM 调用。
- SAM3 只给人物 mask。简单房间的墙/地面由 Agent 选择拓扑后，工具在两侧无人物区域测边界；不是把 SAM 作为唯一来源。
- 诊断输出不可自动接受的复查队列；实体漏检不等于消失，缺证据的轨迹仍是不确定结果。

## 验证与交付

- 29 项单元/回归测试通过，旧 recovery 8 项检查和 visible-surface 已知几何比较另有日志。
- 原 baseline 冻结清单的 35 个引用通过哈希校验。
- review 页面包含原视角、相同全局视角、白模视频、相机数值轨迹、主体/相机轨迹图、逐帧指标和失败记录。
- 前景评估要求正确实例标签；缺失主体不能由后方墙面深度冒充覆盖。真实数据指标只描述与预测深度/辅助 mask 的一致性。
- 保守盒体重叠不是连续无碰撞证明，当前没有宣称穿模已通用解决。

输出以 runs/v4_* 的不可变目录为准，聚合页由 scripts/publish_iterative_v4.py 构建。最终代码快照与输入引用保存在聚合页下；早期 R1 使用其自身 source_snapshot，不能用最终源码冒充早期源码。
